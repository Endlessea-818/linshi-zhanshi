# Guidelines.md

设计与使用规范。用于记录交互、状态切换、使用原则和业务流程。

## 资源调用原则

- 图标、插图和动效资源统一引用 `assets/` 或 `src/assets/` 下的本地路径。
- 不直接引用下载目录或 Figma 临时链接。
- 表单控件状态图标按当前交互状态切换，不用临时 CSS 绘制替代。

## 后台系统交互原则

- 列表页默认使用“状态 Tab + 搜索 / 筛选 + 表格 + 分页”的结构。
- 筛选条件变化后，表格结果和分页计数同步刷新。
- 搜索输入支持回车触发，也应保留搜索图标入口。
- 危险操作需要二次确认或明确的撤销路径。
- 空数据与筛选无结果应区分展示，避免用户误判数据源状态。

## 任职资格业务流程

- 标准库：维护职类、职级、能力项、行为标准和评审规则。
- 认证计划：配置认证周期、适用对象、申报等级、评审人和截止日期。
- 员工申报：员工提交申报资料后进入评审任务池。
- 专家评审：评审人按能力维度给出结论、意见和等级建议。
- 结果归档：通过结果写入员工任职资格档案，未通过结果保留复盘记录。

## 状态建议

- 未开始：中性文字色。
- 进行中：品牌色。
- 待评审：提醒色。
- 已通过：成功色。
- 未通过 / 已退回：警示色。

## 新增页面要求

- 新增页面时先明确属于哪个一级业务模块。
- 页面内的表格、筛选、弹框、空状态优先复用现有样式。
- 新增颜色、控件高度、特殊交互时同步更新 `docs/tokens.md`、`docs/styles.md` 或本文件。
