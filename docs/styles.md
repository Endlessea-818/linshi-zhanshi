# styles.md

样式与布局规则。用于维护尺寸、间距、排版、滚动区域和页面结构。

## 全局布局

- 当前项目为 Web 后台界面，最小响应宽度为 `1100px`。
- 页面由顶部状态栏、左侧导航、右侧内容区组成。
- 右侧内容区外边距 `16px`，核心内容使用白色面板或独立信息块。
- 操作型后台页面优先使用紧凑、可扫描的布局，不使用营销型首屏。

## 顶部状态栏

- 高度：`60px`。
- 状态入口文字：`14px / 20px`。
- 红色数量徽标高度：`18px`，圆角 `9px`。
- 顶部状态栏层级高于内容区固定头部。

## 左侧导航

- 宽度：`220px`。
- 一级菜单高度：`42px`。
- 当前页使用品牌色背景和品牌色文字。
- 当二级菜单处于选中状态时，对应一级菜单文字使用 `font-weight: 500`。

## 表单布局

- 表单控件默认高度统一为 `36px`。
- 表单标签文字 `14px / 36px`，颜色 `#242F57`。
- 单行输入框内边距为上下 `6px`、左右 `12px`。
- 禁用态背景为 `#F0F2F5`，禁用文字为 `#C9CDD4`。

## 表格布局

- 表头高度：`46px`。
- 内容行高度：`46px` 到 `56px`，按业务信息密度确定。
- 勾选 / 序号列宽度：`38px`。
- 常规单元格左右内边距：`12px`。
- 表头文字：`14px / 22px`，字重 `500`。
- 内容纯文本：`13px / 22px`。
- 单元格文本默认单行省略，文本容器必须设置 `min-width: 0`。

## 下拉与浮层

- 通用下拉框白底、`4px` 圆角、`0 0 20px rgba(32, 32, 44, 0.2)` 阴影。
- 下拉选项高度 `32px`。
- 悬停背景 `#F5F7FD`，选中背景 `#E8F3FF`。

## HR 业务页面建议

- 任职资格标准库页面：左侧筛选职类，右侧展示等级标准和能力项。
- 认证计划页面：顶部筛选周期和职类，中部展示计划表格，右侧或弹框编辑评审配置。
- 评审任务页面：使用状态 Tab + 搜索 + 表格 + 分页结构。
- 人才盘点页面：使用指标区、分布表格和能力维度条，保持信息密度。
