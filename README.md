# 人力资源任职资格平台

这是一个基于 Vue 2 + Vue CLI 的后台系统环境底座。项目依赖、构建方式、设计变量、字体、图标素材和基础规范对齐「临床研究智能化管理平台」，暂不包含具体业务界面。

## 本地预览

```bash
npm install
npm run serve
```

## 常用命令

```bash
npm run verify:env
npm run build
```

## 项目结构

- `src/App.vue`：Vue 最小挂载入口，后续业务界面从这里接入。
- `src/styles.css`：全局设计变量、字体、基础 reset 和通用工具类。
- `src/assets/`：由参照项目复用的字体、图标、插图和动效素材。
- `public/assets/`：运行时可直接通过浏览器路径访问的同款素材。
- `docs/`：从新项目角度整理后的环境、组件、样式和设计变量说明。

## 设计约定

- 继续使用参照项目的品牌主色 `#027AFF`、文字色阶、辅助色、Rubik 数字字体和 `36px` 表单控件高度。
- 后台布局后续按顶部状态栏、左侧导航、右侧内容区的结构实现。
- 新增业务页面时优先复用 `src/styles.css` 中的 CSS 变量和 `docs/` 中的组件规范。
- 新增颜色、间距或组件状态时，先同步更新 `docs/` 下的规范文档。
